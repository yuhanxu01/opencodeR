# 量子力学基础 (中文版)

## 1. 波函数

在量子力学中，波函数 ψ(x,t) 描述了粒子的量子态。波函数的模平方 |ψ(x,t)|² 表示在时间 t 和位置 x 找到粒子的概率密度。

## 2. 薛定谔方程

### 2.1 时间相关薛定谔方程

时间相关的薛定谔方程为：

```
iℏ ∂ψ/∂t = Ĥψ
```

其中：
- i 是虚数单位
- ℏ 是约化普朗克常数
- Ĥ 是哈密顿算符

### 2.2 哈密顿算符

哈密顿算符（Hamiltonian operator）定义了系统的总能量，包括动能和势能：

```
Ĥ = -ℏ²/2m ∇² + V(x)
```

其中：
- m 是粒子质量
- V(x) 是势能函数

## 3. 特征值问题

### 3.1 能量本征值

时间无关的薛定谔方程是一个特征值方程：

```
Ĥψ = Eψ
```

这里 E 是能量本征值（特征值），ψ 是对应的本征态（特征向量）。

### 3.2 特征向量的正交性

不同能量本征态满足正交归一化条件：

```
⟨ψₘ|ψₙ⟩ = δₘₙ
```

## 4. 拉格朗日量和哈密顿量

### 4.1 拉格朗日量

在经典力学中，拉格朗日量定义为动能减去势能：

```
L = T - V
```

### 4.2 从拉格朗日量到哈密顿量

哈密顿量可以通过勒让德变换从拉格朗日量得到：

```
H = pq̇ - L
```

其中 p 是广义动量，q̇ 是广义速度。

## 5. 傅里叶变换

量子力学中常用傅里叶变换在位置空间和动量空间之间转换：

```
ψ̃(p) = 1/√(2πℏ) ∫ ψ(x) e^(-ipx/ℏ) dx
```

## 6. 测不准原理

海森堡测不准原理表明位置和动量不能同时精确测量：

```
Δx Δp ≥ ℏ/2
```

这是量子力学的基本限制。
