# 线性代数基础 (中文版)

## 1. 矩阵基础

### 1.1 矩阵定义

矩阵是一个 m×n 的数表，由 m 行 n 列元素组成。

### 1.2 特殊矩阵

- **单位矩阵**：对角线元素为1，其他元素为0
- **对角矩阵**：只有对角线元素非零
- **对称矩阵**：满足 A = Aᵀ
- **正交矩阵**：满足 AAᵀ = I

## 2. 特征值与特征向量

### 2.1 定义

对于方阵 A，如果存在非零向量 v 和标量 λ 使得：

```
Av = λv
```

则称 λ 为矩阵 A 的特征值（本征值），v 为对应的特征向量（本征向量）。

### 2.2 特征值的性质

- 矩阵的迹等于所有特征值之和
- 矩阵的行列式等于所有特征值之积
- 对称矩阵的特征值都是实数

### 2.3 特征向量的正交性

对称矩阵的不同特征值对应的特征向量相互正交。

## 3. 行列式

### 3.1 定义

行列式是一个将方阵映射到标量的函数，记作 det(A) 或 |A|。

### 3.2 性质

- det(AB) = det(A)det(B)
- det(Aᵀ) = det(A)
- det(A⁻¹) = 1/det(A)

## 4. 矩阵分解

### 4.1 特征值分解

对于可对角化矩阵 A：

```
A = PDP⁻¹
```

其中 D 是特征值构成的对角矩阵，P 是特征向量构成的矩阵。

### 4.2 奇异值分解 (SVD)

任意 m×n 矩阵 A 可以分解为：

```
A = UΣVᵀ
```

其中：
- U 是 m×m 正交矩阵
- Σ 是 m×n 对角矩阵（包含奇异值）
- V 是 n×n 正交矩阵

## 5. 向量空间

### 5.1 线性独立

向量组 {v₁, v₂, ..., vₙ} 线性独立当且仅当：

```
c₁v₁ + c₂v₂ + ... + cₙvₙ = 0
```

只有在所有 cᵢ = 0 时才成立。

### 5.2 基和维数

向量空间的基是一组线性独立的向量，它们可以张成整个空间。基中向量的个数称为空间的维数。

## 6. 内积和范数

### 6.1 内积

两个向量的内积定义为：

```
⟨u, v⟩ = u₁v₁ + u₂v₂ + ... + uₙvₙ
```

### 6.2 范数

向量的范数（长度）定义为：

```
‖v‖ = √⟨v, v⟩
```
