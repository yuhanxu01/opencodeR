## 📝 API 端点

### 会话管理
- `GET /session` - 获取所有会话
- `POST /session` - 创建新会话
- `DELETE /api/session/:id/` - 删除会话（Django 代理）
- `GET /session/:id/message` - 获取会话消息

### 消息处理
- `POST /session/:id/prompt_async` - 发送异步消息

### 权限管理
- `GET /permission` - 获取待处理权限
- `POST /permission/:id/reply` - 回复权限请求

### 配置
- `PUT /auth/deepseek` - 保存 DeepSeek API 密钥

### 实时事件
- `GET /event` - SSE 事件流
